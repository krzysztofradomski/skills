install

Three ways in. Each links the skill into Claude Code, and into Codex too when it is installed. Then start a new agent session — skills load at startup.

Ask your agent

Paste this into Claude Code or Codex. It reads the repo and does the rest.

Install the skills from https://github.com/krzysztofradomski/skills — clone it, then symlink the skills into my agent skill directory and any bundled scripts onto my PATH. Show me what you linked.

One command

Clones to ~/.local/share/agent-skills, links the skills, puts scripts on your PATH. Re-run it to update. It skips anything that is already a real directory rather than overwriting it.

curl -fsSL https://raw.githubusercontent.com/krzysztofradomski/skills/main/install.sh | bash

Piping a stranger's script into your shell is a habit worth resisting — download it and read it first if you would rather. It is about sixty lines.

By hand

Symlinks, not copies, so git pull updates everything with nothing to reinstall.

git clone https://github.com/krzysztofradomski/skills.git ~/code/skills
cd ~/code/skills
ln -s "$PWD/delegate" ~/.claude/skills/delegate
ln -s "$PWD/delegate" ~/.codex/skills/delegate
ln -s "$PWD/delegate/scripts/delegate.sh" ~/.local/bin/

what it actually does for you

  • picks a model that fits the job — a rename does not need the model you would hand a security review, and a security review should not go to the fast one.
  • reviews across vendors — inside Claude Code, Codex reviews your diff; inside Codex, Claude does. In the session above that caught a real hole in a guard Claude had just written.
  • checks that work actually happened — after a write it verifies the files changed, because some models report success having touched nothing.
  • never spends money quietly — two free image paths run first, and the paid one needs an explicit flag.
